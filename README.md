# CUMCM Math Modeling Codex Skill

这是一个面向全国大学生数学建模竞赛（CUMCM）和同类竞赛的 Codex
skill。它把一次建模任务拆成可复核的工作流：读题、附件审计、路线比较、
逐问建模、代码求解、图表生成、结果验证、论文写作和最终审稿。

它不是“一键获奖”工具。它的核心目标是让每一问都形成闭环：模型讲得清、
代码跑得出、结果有来源、验证能支撑，最后都写回 `paper/main.tex`。

## 适合什么任务

- 国赛、华东杯、校赛等竞赛式数学建模题。
- 需要从题面和附件出发，完成建模、求解、图表、验证和论文。
- 需要把代码结果转成可提交的中文 TeX 论文。
- 需要检查模型是否空泛、结果是否可追溯、摘要是否和正文一致。

不适合普通作业代写、单纯润色文章、只改图片、只修代码，除非这些工作服务于
一份竞赛建模论文。

## 安装

在 Codex 中直接说：

```text
请安装这个 skill：https://github.com/usst-yk/cumcm-math-modeling-codex-skill
```

安装后重启 Codex。使用时建议显式调用：

```text
[$cumcm-math-modeling] 请先解析这道数学建模题，不要急着建模。
```

## 30 秒开始

刚拿到题：

```text
[$cumcm-math-modeling] 这是我的赛题和附件。请先读题，拆解每一问，检查附件数据，然后给出建模路线。暂时不要直接写完整论文。
```

只做某一问：

```text
[$cumcm-math-modeling] 我只负责第 1 问。请完成题意分析、建模思路、变量公式、求解方案、验证方法、必要图表和可写入论文的正文。
```

已有代码和结果，要写论文：

```text
[$cumcm-math-modeling] 请根据当前代码、结果表和图片写论文段落。论文里的关键数字必须能在结果文件中找到来源，并写入 paper/main.tex。
```

更多可复制提示词见 `examples/README.md`。

## 推荐工作流

不要一开始就要求“直接求解整题并写完整论文”。更稳的顺序是：

1. 读题，拆每一问，检查附件和单位。
2. 比较基线路线、主路线和备选路线。
3. 每一问先写 `modeling/qx_modeling_idea.md`，再写代码。
4. 代码出结果后，反向核对模型、公式、约束和结果来源。
5. 补齐结果表、中文图、流程图、验证图和敏感性分析。
6. 每完成一问就更新 `paper/main.tex`。
7. 正文完成后统一符号、图表、数字和结论，最后写摘要。

## 默认输出目录

普通建模任务默认围绕这些目录组织：

```text
problem/          题面原文、题意解析、每问任务拆解
data/             原始数据、清洗数据、预处理结果；不要写成 date/
modeling/         每一问的详细建模思路、公式、验证方案、GPT-image 流程图提示
src/              数据处理、模型求解、绘图和验证代码
tables/           数据审计表、结果表、约束检查表、敏感性分析表
figures/          论文图片，包括 GPT-image 流程图、结果图、验证图
results/          验证报告、结果来源说明、最终校验记录
paper/main.tex    唯一论文入口文件
```

`paper/main.tex` 是最终交付物的中心。单问、全题、补图、验证、摘要和审稿
都默认服务于这个文件。

## 质量底线

- 关键数字必须能追溯到题面、附件、代码输出、结果表、图片或验证报告。
- 每一问都要有清楚的变量、假设、公式或评价准则、约束、算法和验证。
- `modeling/qx_modeling_idea.md` 不能只是公式列表，必须解释模型如何从题意推出来。
- 优化问题不能在没有 solver status、可行性检查或证明时声称全局最优。
- 预测问题不能在没有误差指标或基线比较时声称精度高。
- 流程图和技术路线图默认作为 GPT-image 论文图保存到 `figures/`。
- 最终交付不要留下“待补充”占位，除非用户明确要求草稿。

## 示例和 benchmark

- `examples/README.md`：按阶段复制的常用提示词。
- `examples/single_question_minimal/`：只做一问时的最小闭环示例。
- `examples/full_problem_demo/`：小型完整题示例。
- `examples/real_cases/`：真实题面 benchmark，用于检查工作流和短板，不是标准答案。
