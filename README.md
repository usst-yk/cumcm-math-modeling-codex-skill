# CUMCM Math Modeling Codex Skill

这是一个面向全国大学生数学建模竞赛（CUMCM）的 Codex skill，用来帮助完成：

读题、附件检查、逐问建模、代码求解、中文图表、验证分析和论文写作。

它不是自动获奖系统，也不是一键生成整篇论文的工具。更推荐把它当作建模队伍的协作助手：先读题，再建模，再求解，最后把结果写回论文。

## 安装

在 Codex 中直接说：

```text
请安装这个 skill：https://github.com/usst-yk/cumcm-math-modeling-codex-skill
```

安装后重启 Codex。使用时建议显式调用：

```text
[$cumcm-math-modeling] 请先解析这道数学建模题，不要急着建模。
```

## 最简单的用法

刚拿到题时：

```text
[$cumcm-math-modeling] 这是我的赛题和附件。请先读题，拆解每一问，检查附件数据，然后给出建模路线。暂时不要直接写完整论文。
```

只做某一问时：

```text
[$cumcm-math-modeling] 我只负责第 1 问。请完成题意分析、建模思路、变量公式、求解方案、验证方法、必要图表和可写入论文的正文。
```

已经有代码或结果，要写论文时：

```text
[$cumcm-math-modeling] 请根据当前代码、结果表和图片写论文段落。论文里的关键数字必须能在结果文件中找到来源，并写入 paper/main.tex。
```

更多可直接复制的提问方式见：

```text
examples/README.md
```

## 默认输出文件

普通建模任务默认只围绕下面这些文件夹组织。新手主要看这些就够了：

```text
problem/          题面原文、题意解析、每问任务拆解
data/             原始数据、清洗数据、预处理结果；不要写成 date/
modeling/         每一问的详细建模思路、公式、验证方案、GPT-image 流程图提示
src/              数据处理、模型求解、绘图代码
tables/           核心结果表、约束检查表、敏感性分析表
figures/          论文图片，包括 GPT-image 流程图、结果图、验证图
results/          关键结果登记、验证报告、论文数字来源
paper/main.tex    论文入口文件；单问和全题都默认写回这里
```

默认交付不要再额外发明一套目录。示例案例里如果看到 `logs/`、
`build/`、`appendix/`、案例内 `references/` 或压缩包，那只是历史案例、
运行记录、编译缓存、附录材料或打包产物，不是新项目必须生成的默认目录。

其中：

- `paper/main.tex` 永远是论文主文件。做题、建模、验证和写作的结果最终都要回到这里。
- 模型流程图和技术路线图默认用 GPT-image 生成，提示词和图注放在 `modeling/`，成图放在 `figures/`。
- 结果图、验证图和敏感性图应来自代码、表格或数据，不能只写结论不留来源。
- 关键数字必须能追溯到题面、数据、代码输出、结果表或 `results/`。

## 新手只需要记住

不要一开始就要求“直接求解整题并写完整论文”。更稳的顺序是：

1. 先读题和检查附件。
2. 再比较几条建模路线。
3. 每一问先写清建模思路，再写代码。
4. 代码跑完后反向核对模型和结果来源。
5. 补齐流程图、结果图、验证图。
6. 最后总装 `paper/main.tex`，摘要最后写。

如果你第一次做数学建模，直接从 `examples/README.md` 的“第一次做建模：直接复制这 7 步”开始。
