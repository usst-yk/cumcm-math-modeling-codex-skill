# Real Cases

这里存放真实数学建模赛题案例。它们用于展示 skill 面对真实题面和附件时的组织方式，不作为自动评测用例。

| Case | Purpose |
| --- | --- |
| `cumcm_2025_a/` | 2025 年国赛 A 题材料：题面 PDF、附件模板、题面解析、任务计划和数据审计。 |
| `huadong_cup_a/` | 华东杯 A 题“游览路线规划问题”：无官方附件场景下的透明 benchmark 数据、路线规划、实时重规划、图表、验证和 TeX 论文闭环。 |

真实案例通常比 `full_problem_demo/` 更重。建议只提交题面、附件、解析结果和必要的中间产物；完整解答、最终论文和大文件数据按需要再补。
