# 2025 年 CUMCM B 题：碳化硅外延层厚度的确定

来源：

- 官方赛题页：https://www.mcm.edu.cn/html_cn/node/03c91a444e62eee81a3740fa97a461a6.html
- 题面 PDF 镜像：https://col.gxmzu.edu.cn/mathmod/UploadFiles/B%E9%A2%98.pdf

本案例不复刻官方附件数据。它抽象 B 题的核心数据结构，构造可验真值的
mini 光谱数据，用于测试 skill 的代码执行、结果追溯、图表生成和验证链路。

## 题目摘要

B 题研究红外干涉法测定外延层厚度。题面说明，红外光入射到外延层后，
外延层表面和衬底界面的反射光会形成干涉条纹，可根据红外光谱的波长、
外延层折射率和入射角确定外延层厚度。官方附件为若干 Excel 文件，每个
文件两列：波数（单位 cm^-1）和反射率（单位 %）。

## 本测试案例

为了检查代码能否准确执行，本案例设置：

- 材料：碳化硅外延层。
- 折射率：`n = 2.55`，作为 mini benchmark 的已知常数。
- 真实厚度：`d = 8.000 um`。
- 入射角：`10 deg` 和 `15 deg` 两组。
- 合成附件：`data/sic_10deg_synthetic.csv`、
  `data/sic_15deg_synthetic.csv`。

测试目标是从合成反射率-波数曲线中反演厚度，要求两组估计值均满足：

```text
abs(estimated_thickness_um - 8.000) <= 0.050
```

这个案例不是 B 题标准答案，只用于回归测试：它保留官方题型的物理结构，
同时让正确性可由已知真值直接判断。
