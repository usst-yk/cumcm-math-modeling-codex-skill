# Rebuild Findings

本次按 examples/README.md 的流程从题面和附件重新生成产物，发现以下问题：

1. 题面解析能识别五个子问题，但工程物理题的几何判据仍需要人工确认。
2. 数据附件是结果模板，不是观测数据；data audit 的价值主要是确认模板 sheet 和字段，而不是建模输入。
3. Q1/Q2 的单弹链路较完整，但 Q3 的同航向多弹联合优化仍然偏弱。
4. Q4/Q5 能形成可复现 benchmark，但属于 best-found 方案，应避免写成全局最优。
5. 最值得继续优化 skill 的方向是：增加多弹联合优化模板、完整圆柱目标遮蔽判据、以及自动从结果表生成 TeX 结果段。
