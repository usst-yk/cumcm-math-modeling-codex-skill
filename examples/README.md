# Examples

这些示例用于告诉学生“可以怎样直接开口”，也用于维护者检查 skill 的覆盖面。

## 常用提示

| 场景 | 文件 |
| --- | --- |
| 完整赛题推进 | `prompt_full_problem.md` |
| 只做某一问 | `prompt_single_question.md` |
| 根据代码和结果写论文 | `prompt_code_to_paper.md` |
| 生成技术路线图 | `prompt_roadmap.md` |
| 提交前评委视角终审 | `prompt_final_review.md` |

## 完整 Demo

`full_problem_demo/` 是一个小型完整示例，包含：

- 题目；
- 原始数据；
- 任务计划；
- 求解代码；
- 结果表和图；
- 结果注册表；
- 验证报告；
- 论文片段。

这个 demo 不代表真实竞赛难度，它的作用是展示“可追溯、可检查、能写入论文”的交付形态。
