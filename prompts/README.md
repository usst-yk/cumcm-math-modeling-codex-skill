# Prompt Rules

这个目录解决新手提示词太短的问题。用户可以直接说“帮我求解第一问”
“修改摘要”“建立更深的模型”“还有哪些模型可以考虑”“可以直接推导吗”
“帮我检查”这类短句；skill 会自动补全成完整任务。

默认读取顺序：

1. 先读 `intent-map.md` 判断真实意图。
2. 再按任务只读一个或少数几个细分文件：
   - `solve.md`：求解单问或整题。
   - `modeling.md`：模型选择、公式推导、模型加深、模型优化。
   - `writing.md`：摘要、论文正文、图表取舍、代码结果写进论文。
   - `validation.md`：验证、敏感性、误差、基线。
   - `review.md`：评委式检查、冲奖检查、临近提交补救。
3. `auto-complete.md` 只保留入口说明和兼容导航，不再承载全部细节。

原则：不要求用户写长 prompt，不把短句理解成低质量交付，所有有效工作最终都回到
`paper/main.tex`。
