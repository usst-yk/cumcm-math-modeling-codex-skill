# Figure Plan

精简输出不等于少画图。对新手来说，图是理解模型最快的材料；少的是空模板和内部日志，不是示意图。

## Default Figure Requirement

每个被求解的子问题，在开始写代码或论文前先做一个简短图表计划。

默认至少生成：

1. `fig_qx_model_schematic.png|svg`：模型/题意/机制示意图。
2. `fig_qx_result.png`：核心结果图。

如果有验证、误差、约束或敏感性分析，再生成：

3. `fig_qx_validation.png` 或 `fig_qx_sensitivity.png`。

对优化、预测、评价排序、调度、仿真这类需要证明可靠性的题目，第三张检查图通常不是可省项。只有当检查结果用 1 个很小的表格更清楚时，才可以不画，并说明原因。

只有在“紧凑表格明显比图更清楚”时才可以少画图，并在最终回复里说明为什么没画。

## Full Problem Figure Set

完整赛题通常需要：

- `fig_problem_overview.png|svg`：题面对象、坐标系、数据流或任务范围示意。
- `fig_route_overview.svg`：技术路线图或逐问流程图。
- 每个已求解子问题至少 2 张图：模型示意图 + 结果图。
- 关键验证或敏感性分析再加 1 张图。

这不会和“精简输出”冲突，因为这些图是论文需要的结果，不是空模板。

## Figure Types By Task

| Task type | First figure | Second figure | Optional check figure |
| --- | --- | --- | --- |
| 预测 | 数据时间线/变量关系图 | 预测曲线与基线对比 | 残差图、误差分布 |
| 优化 | 决策变量、约束、流程示意图 | 方案结果图、成本/收益分解 | 约束违反检查、敏感性曲线 |
| 调度 | 时间线、资源流或网络示意图 | 甘特图、路径图、资源占用图 | 可行性/冲突检查图 |
| 评价排序 | 指标体系图 | 排名条形图、权重图 | 排名稳定性或权重扰动图 |
| 仿真 | 机制流程或状态转移图 | 关键状态随时间变化图 | 参数扰动图 |
| 几何/空间 | 坐标系、对象位置、轨迹示意图 | 距离、覆盖、路径或布局结果图 | 边界点/约束可行性图 |
| 分类/聚类 | 特征空间或流程图 | 聚类/分类结果可视化 | 混淆矩阵或误判样例 |

## Chinese Figure Rules

- 图题、坐标轴、图例、注释默认中文。
- 字号按 `references/figure-standards.md`，源图字号要偏大，插入论文后接近正文。
- 长标签换行，不要缩成小字硬塞。
- 每张图必须能对应一句论文结论。

## Skip Rules

不要因为“赶时间”跳过示意图。可以跳过的情况只有：

- 题目是纯符号推导，图会误导；
- 当前输出只是口头建模路线，没有要求生成文件；
- 表格比图更清楚，例如只有 3 个标量结果；
- 用户明确要求“不画图”。

跳过时要写一句原因。
