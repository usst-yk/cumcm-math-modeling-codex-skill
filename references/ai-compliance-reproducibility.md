# AI Compliance And Reproducibility

AI assistance is acceptable only when the paper makes evidence boundaries
clear. Separate data-derived figures, illustrative figures, and code-produced
results so readers can tell what is measured, what is computed, and what is
explanatory.

## Artifact Classes

### Data-Derived Figures

Examples: plots from attached data, computed routes, prediction curves,
validation errors, sensitivity curves, constraint checks.

Rules:

- generated by script or traceable manual processing;
- source data, preprocessing, code path, and output file must be recorded;
- captions may state quantitative conclusions only if values come from the
  saved table, figure data, or code output;
- must be reproducible from project files.

### Illustrative Figures

Examples: mechanism schematic, workflow diagram, conceptual scene, AI-assisted
visual brief, problem overview not based on measured data.

Rules:

- caption should say `示意图` or otherwise make the illustrative status clear;
- no invented data values, measured geometry, real map claims, or fake samples;
- may explain mechanism, variables, or workflow, but not prove a result;
- AI-generated drafts must have a brief and should not be treated as evidence.

### Code Results

Examples: tables, metrics, optimized decisions, predictions, rankings,
simulation outputs.

Rules:

- code, parameters, random seed when relevant, and run command should be
  recoverable;
- headline numbers must appear in result tables, logs, or registry rows;
- rerunning should reproduce the same values or explain allowed tolerance;
- stochastic results need seed, repeat count, and summary statistic.

## Suggested Statement

Use a short reproducibility note when AI or scripts contributed:

`本文中的数据图和数值结果由项目代码基于题目数据生成；示意图仅用于说明模型结构或流程，不作为数值证据。AI 工具仅用于文字润色、示意图 brief 或非数据性视觉草稿，未用于伪造数据、实验结果或代码输出。`

## Final Checks

- Every figure is classified as data-derived, illustrative, or code result.
- Every quantitative claim has a traceable source.
- AI figure briefs do not contain fabricated data instructions.
- Reproduction steps are sufficient for another user to regenerate the reported
  tables and data-derived figures.
