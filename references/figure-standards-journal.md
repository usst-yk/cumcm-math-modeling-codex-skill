# Journal Figure Standards

Use this only when the user explicitly asks for SCI, Nature, PRL, journal-grade, or publication-style scientific figures. For ordinary CUMCM papers, use `references/figure-standards.md`.

## Additional Requirements

- Decide target format before plotting: single-column, double-column, poster, PPT, or journal submission.
- Prefer PDF for line art and high-DPI PNG/TIFF for raster images when required.
- Maintain consistent font family, panel labels, line widths, marker sizes, and color palette across the figure set.
- Use colorblind-safe palettes and avoid color-only encoding.
- Report statistical tests, error definitions, sample sizes, and preprocessing choices in captions or methods.
- Keep source data and plotting scripts sufficient for exact regeneration.

## Typical Dimensions

- Single-column journal figure: about 85-90 mm wide.
- Double-column journal figure: about 170-185 mm wide.
- CUMCM paper figures can be wider and use larger text for judge readability.

## When Not To Use

Do not apply this heavier standard to routine contest charts if it would make the figure harder for judges to read quickly.
