# Citation Policy

CUMCM papers do not need many references, but method citations can help when they are real and relevant.

## Rules

- Do not fabricate references.
- Prefer textbooks, official documentation, classic method papers, or reliable algorithm references.
- Every BibTeX entry must include title, author or organization, year, source, and DOI/URL when available.
- Cite method origins sparingly; do not let references replace model explanation.
- If a reference cannot be verified, mark it as `待真实文献补充`.

## Suggested Use

- Optimization solvers: cite solver documentation or algorithm family references.
- Time series: cite model textbook or package documentation.
- TOPSIS/AHP/entropy weighting: cite a verified source only when the method materially affects the paper.
