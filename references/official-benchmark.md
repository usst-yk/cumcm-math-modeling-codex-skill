# Official Benchmark Sources

Use this file when judging whether a modeling route is contest-grade. These
sources are reference signals, not answer keys. Do not copy protected paper
images or long text into outputs.

## Source Types

1. Contest problem reviews from the official CUMCM channel.
2. Displayed excellent papers from the official CUMCM paper showcase.
3. Expert talks on good modeling papers and modeling method training.

## How To Use

- For a new contest problem, first identify the closest historical task type:
  engineering simulation, optimization, prediction, evaluation, scheduling,
  classification, clustering, or hybrid.
- Read the matching problem review when available. Extract only the evaluation
  intent: key mechanism, common mistakes, expected validation, and paper risks.
- Use displayed papers as structure references: section order, figure density,
  result traceability, and validation placement.
- Use expert talks as general rubric references, especially for model clarity,
  assumptions, verification, and paper readability.

## Benchmarking Rules

- Do not claim a route is first-prize level only because it uses an advanced
  algorithm.
- Prefer routes that explain the physical, operational, statistical, or
  evaluation mechanism of the problem.
- Require a simple baseline before complex modeling.
- Require validation that matches the task type.
- Require figures that reveal the model mechanism and result, not decorative
  diagrams.
- Treat official paper showcases as examples of presentation quality, not as
  universally optimal modeling choices.
