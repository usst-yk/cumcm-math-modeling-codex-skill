# Assets

`assets/` 存放可复制或可改写的文档素材，不是按需读取的规则文件。

| Asset | Purpose |
| --- | --- |
| `paper-template.md` | Markdown 论文模板。 |
| `paper-template.docx` | Word 论文模板。 |
| `assumptions-symbols-template.md` | 假设和符号说明模板。 |
| `appendix-code-template.md` | 附录代码说明模板。 |

区别：`templates/` 用于自动初始化项目；`assets/` 用于提供人类可继续编辑的素材。
