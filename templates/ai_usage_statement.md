# AI Usage Statement

This project may use AI tools for workflow assistance, including problem parsing, task planning, code drafting, figure brief drafting, and presentation assembly. All mathematical claims, numerical results, tables, and figures must be verified against reproducible scripts, source data, or manual checks before final submission.

## Usage Log

| Stage | Tool/Agent | Purpose | Human verification |
| --- | --- | --- | --- |
| Problem analysis | TBD | Extract subquestions, inputs, outputs, and risks | Checked against original problem statement |
| Modeling/code | TBD | Draft scripts or modeling alternatives | Re-run commands and validate outputs |
| Figure/paper | TBD | Draft captions, figure briefs, or text | Cross-check with result registry |

## Commitments

- AI output is treated as draft material, not as evidence.
- Numerical conclusions must appear in `results/result_registry.csv` or an equivalent traceable record.
- Generated figures must not introduce unsupported data, labels, or claims.
- Final wording must disclose limitations and uncertainty where the evidence is incomplete.
